---
name: Profile annotation experience
description: Product direction for presenting LinkedIn profile analysis and original-document evidence.
---

Make the responsive LinkedIn-style reconstructed profile the primary analysis view. Show recommendations beside the wording they address, with transparent keep, improve, opportunity, conflict, and unverified states. Offer the privately stored original LinkedIn PDF as a supporting evidence view with anchored highlights.

**Why:** Users understand recommendations more easily in profile context, while the original document helps them verify that BrandMoi read their source correctly. The reconstructed view remains usable for pasted text and across mobile layouts.

**How to apply:** Connect headline, About, role, experience-bullet, and skills recommendations to their displayed source text. Never force a low-confidence PDF coordinate match; fall back to a section-level annotation. Keep original files private, owner-accessible, replaceable, and deletable.
