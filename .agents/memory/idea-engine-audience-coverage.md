---
name: Idea Engine audience coverage
description: Audience coverage and density rules for BrandMoi's Idea Engine modes.
---

Standalone Idea Engine modes should deliberately cover Clients, Peers, Recruiters & Headhunters, Investors, and My audience instead of treating the profile's broad audience as one generic group.

**Why:** Generic targeting can make distinct ideas converge on the same premise. Explicit coverage makes the intended reader and value of each idea visible. Best Posts is already grouped by source post, so five variants per source would create an overwhelming list.

**How to apply:** Return one result per core audience for Brand, Teach, Pain Points, and Skills. For grouped performance-derived suggestions, keep the existing small number of angles, target different audiences, and label each audience in the interface and writing handoff.
